# Cobalt Balance — Descargas

Instaladores del programa de contabilidad **Cobalt Balance** (Cobalt Studio LLC).

Descárgalo desde **https://cobaltbalance.com** o en la sección **Releases** de este repositorio.

- **Windows 10 y 11:** `Cobalt-Balance-Windows-x64.zip`
- **Mac (prueba, sin firma de Apple todavía):** `Cobalt-Balance-Mac-arm64.zip` (chip M) y `Cobalt-Balance-Mac-x64.zip` (Intel)

Este repositorio solo contiene los instaladores; el código del programa es privado.
